# Implementation baseline — 2026-11-08

Scope: repository audit and tests, not W2 implementation. Browser-demo v1.0 and W1–W6 are separate tracks. User reports v1.0 accepted; `docs/ACCEPTANCE.md` still documents unverified v1.0 criteria, so that report is not independent proof of complete technical acceptance.

## Existing implementation

- Seven ordered stations and stable IDs `loader`, `printer`, `spi`, `mounter`, `reflow`, `aoi`, `unloader`: `src/data/stations.ts`. `src/scene/Factory.tsx` renders, selects, focuses and orbits them; `src/app/App.tsx` provides controls, accessible station list, disclaimer, WebGL fallback and simulated status. Responsive styles: `src/styles/`.
- Blender sources `assets/blender/{printer,mounter}.blend`, generated by `assets/blender/generate_models.py`; local GLBs `public/models/{printer,mounter}.glb`. Printer and mounter use these static shells with procedural fallback; all other shells and all process animation are procedural. Five remaining stations are not five distinct asset designs: they share a shell with an oven variant and station-specific mechanisms. Named GLB motion anchors are placeholders. See `tests/unit/assets.test.ts` and `tests/e2e/models.spec.ts`.
- `src/simulation/engine.ts`: pure TypeScript deterministic virtual-time engine, LCG seed, bounded input FIFO and one processing/output-hold slot per station, downstream-first settlement, capacity-checked instantaneous transfers, mounter fault freeze/resume and SPI/AOI inspection. Failed inspections continue through the line. Defaults in `src/data/scenario.ts` are 100 boards, seed 2026, defect rate 0.03 and capacity 2.
- `src/domain/replay.ts` reconstructs an in-memory snapshot from ordered events through an inclusive timestamp; same-time events are applied in order. `src/domain/analytics.ts` computes synthetic KPIs. `src/presentation/presentation.ts` supplies the guided tour. Logs are not durable; reset discards them. Existing events use `{id,schemaVersion,simTimeMs,sequence,type,payload}`, not the W2 envelope; there is no `runId`, source or wall-clock emission timestamp.
- No Go module, MQTT contract, broker configuration, backend, Compose stack or independent simulator found in project files. Existing mock MES is browser-local presentation data, not an external service. W3–W6 remain roadmap work, not inferred from browser features.
- Known limitations: visual transfers jump between stations, GLB anchors are not animated, separate LODs and representative-GPU performance measurements are missing, full guided tour and external deployment not independently verified. See `README.md` and `docs/ACCEPTANCE.md`.
