# v1.0 Presentation Mode Implementation Plan

**Goal:** Add a repeatable 3–5 minute guided concept demonstration, per `docs/PROJECT_PLAN.md` v1.0.

**Architecture:** A pure presentation controller advances the existing simulator in fixed virtual-time segments and applies fault/recovery actions exactly at scripted boundaries. React consumes the resulting snapshot and chapter to select existing camera presets and render narrative controls; historical replay and KPI selectors remain independent.

**Tech Stack:** Strict TypeScript, React, R3F, Vitest, Playwright, static Vite build.

## Tasks
- [ ] Test repeated scripted event logs, chunk-independent fault timing, pause/resume and reset; implement controller and chapter definitions.
- [ ] Add accessible presentation start/pause/resume/restart/exit and camera/narrative/KPI summary; preserve manual mode and replay.
- [ ] Test browser interaction and offline/static build; document demo usage, provenance, deployment, screenshots and known gaps.
- [ ] Run lint, typecheck, unit, build and E2E; report acceptance honestly.

## Constraints and review focus
- Script actions use virtual timestamps, not render frames or wall clock.
- No live equipment, external APIs, proprietary geometry or fabricated telemetry.
- Repeated full runs with identical inputs produce identical event logs.
- Pause must freeze virtual time and avoid accidental manual simulation operations during presentation.
- Asset failure uses procedural fallback; prior v0.3/v0.6 validation gaps remain disclosed.
