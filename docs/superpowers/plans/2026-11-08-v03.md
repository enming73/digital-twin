# v0.3 Machine Process Animations Implementation Plan

**Goal:** Add explicitly illustrative machine motions driven by simulated machine state and virtual time, per `docs/PROJECT_PLAN.md`.

**Architecture:** Pure pose functions map station snapshots and virtual time to bounded procedural transforms. React Three Fiber consumes those transforms and does not advance simulation time. Existing station focus provides close-up presets; the UI labels motion illustrative.

**Tech Stack:** Strict TypeScript, React Three Fiber, Vitest, Playwright.

## Tasks
- [ ] Test deterministic bounded poses, stopped machine behavior, pause and speed equivalence; implement pose functions.
- [ ] Add named animated assemblies for loader, printer, SPI, mounter, reflow, AOI and unloader; bind to virtual snapshots.
- [ ] Add close-up control and illustrative labels; test browser behavior.
- [ ] Verify PCB transfer limitations, document decisions, run all checks, stop before v0.4.

## Constraints and review focus
- No simulation time from render frames; no proprietary geometry or implied measured coordinates.
- Pause and non-running station states must not continue cycling.
- Reset/same snapshot must give the same pose; speed changes affect only virtual time.
- Fault injection and interactive seek are v0.5 features, not invented in v0.3.
- PCB transfer interpolation must not falsify ownership or hide a lack of simulated transfer duration.
