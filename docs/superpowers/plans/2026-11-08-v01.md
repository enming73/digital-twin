# v0.1 Factory Scene Implementation Plan

**Goal:** Deliver the seven-station conceptual factory scene described in `docs/PROJECT_PLAN.md` without starting simulation work.

**Architecture:** A typed, rendering-independent station configuration drives a procedural R3F scene and accessible React controls. Camera focus consumes station presets; static props never represent live telemetry.

**Tech Stack:** Vite, React, strict TypeScript, R3F, Drei, Vitest, Playwright.

- [ ] Bootstrap tooling; test station identity, layout and camera configuration before implementation.
- [ ] Build procedural industrial scene and selectable station controls; verify via browser smoke tests.
- [ ] Document assumptions and phase acceptance; run lint, typecheck, unit tests, build and E2E.
