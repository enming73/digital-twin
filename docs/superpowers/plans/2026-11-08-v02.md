# v0.2 Deterministic Simulator Implementation Plan

**Goal:** Implement v0.2 of `docs/PROJECT_PLAN.md`: deterministic, bounded FIFO board flow and browser controls.

**Architecture:** A pure TypeScript event scheduler owns virtual time, seeded inspection outcomes, board identities, station queues and immutable events. A browser timer converts elapsed wall time and speed into explicit virtual-time advances; React and the scene consume snapshots only.

**Tech Stack:** TypeScript, React, R3F, Vitest, Playwright.

## Tasks
- [ ] Test and implement deterministic scheduler, configuration validation, FIFO transfers, blocked capacity, no-loss completion and seeded inspection.
- [ ] Test and implement pause/resume/reset and speed conversion independently of rendering.
- [ ] Bind snapshots to controls, counters and PCB visualization; add browser smoke coverage.
- [ ] Document simplifications and execute all checks; stop before v0.3.

## Review focus
- Reject empty stations, nonpositive capacities/durations, invalid quantity and defect rates.
- Simultaneous completions have deterministic ordering; repeated seeds produce identical logs.
- Slow downstream machines fill bounded queues and block upstream without losing or duplicating boards.
- Pause freezes virtual time; speed changes only wall-time conversion.
- Reset returns to a clean initial state; completed runs do not create new boards.
